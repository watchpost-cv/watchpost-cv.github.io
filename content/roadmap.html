Roadmap

Prove the monitoring loop first.

Watchpost has useful server foundations, but it is not yet an end-to-end monitoring product. Earlier component-level completion claims have been withdrawn.

WP01R · Honest reconciliation — complete

Working, partial, misleading, and absent behaviour has been inventoried. The remote-host workflow is the active priority.

WP02R · Collector contract

Freeze identity, observation, time, sequencing, retry, compatibility, and freshness contracts.

WP03R · Linux collector

Ship real CPU, memory, disk, load, uptime, and collector-health sampling.

WP04R · Secure pairing

Use a short-lived one-use pairing token to write local collector configuration without manually copying a permanent secret.

WP05R · Service lifecycle

Install, operate, inspect, upgrade, and uninstall the collector safely with systemd.

WP06R · Reliable delivery

Persist sequence state, buffer bounded telemetry, retry with backoff, and replay in order after disconnection.

WP07R · Explicit collector health

Represent healthy, stale, offline, skewed, rejected, partial, and never-connected states without turning absence into zero.

WP08R · Complete host journey

A user pairs a second Linux process, sees continuing graphs, creates starter rules, restarts both ends, and collection recovers.
