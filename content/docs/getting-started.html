Getting started

Watchpost now has a runnable development service through WP11. It is not a public release and should not yet be exposed to the internet, but the source builds into an authenticated single-node monitoring runtime.

Run the development service

git clone https://github.com/watchpost-ops/watchpost.git
cd watchpost
go run ./cmd/watchpost serve

The default listener is 127.0.0.1:8080. The current runtime includes migrated SQLite storage, first-administrator setup, sessions and capabilities, post inventory, collector ingestion, Linux host snapshots, endpoint checks, bounded history, deterministic alerts, notification delivery, and durable incidents.

Development boundary

No release artifacts, supported upgrades, production collector agent, or complete hardening programme exist yet. Use this build for development and review, not internet-facing operations.

Configuration

--listen and --data-dir override WATCHPOST_LISTEN and WATCHPOST_DATA_DIR. Defaults apply below both. Stop Watchpost before copying its SQLite data directory; tested online backups arrive later.
