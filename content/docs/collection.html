Docs · Operate

Collection

Collection is where operational truth enters Watchpost. Every observation has a post identity, source, event time, ingestion time, quality, and bounded payload.

Immediate checks

The Run a check view performs an immediate HTTP, ICMP, TCP, DNS, or TLS check. These are useful for enrollment and diagnosis.

HTTP  https://example.com/health
TCP   database.internal:5432
DNS   api.internal.example
TLS   example.com:443  server name: example.com

A failed check reports failure rather than manufacturing a healthy value. TLS server name is only required when certificate validation must use a name different from the address.

Host and push collection

Authenticated collectors push bounded observations to the observation endpoint. Each collector belongs to one post and receives a secret once during enrollment.

{
  "post_id": "api-01",
  "signal": "cpu.percent",
  "value": 71.4,
  "quality": "good",
  "observed_at": "2026-08-28T00:00:00Z"
}

Read-only SNMPv3

The SNMP setup guide uses authPriv with SHA-256 authentication and AES privacy. Enter the address and credentials, select a bounded device kind, add no more than 64 named OIDs, then test the connection.

name: uptime
oid:  .1.3.6.1.2.1.1.3.0
unit: ticks

Initial device coverage prioritizes network devices, UPS/PDU equipment, environmental sensors, and storage appliances because their read-only health signals are broadly useful and have established SNMP conventions.

Logs and changes

Use Evidence to add or search bounded logs. Messages are capped and credential-like text is redacted. Change records capture deployments, configuration updates, maintenance, or other operational context.

Future devices

Cameras, arbitrary consumer IoT, PLC writes, and building-control commands remain future exploration areas rather than permanent exclusions. Camera work should begin with availability and health rather than video ingestion. Consumer IoT requires bounded adapters. PLC writes and building-control commands require a separate threat model and must never be presented as safety control.

Collector invariant

Failure, lateness, and partial data remain visible. Old data is not silently presented as current, and missing observations are not converted to zero.
