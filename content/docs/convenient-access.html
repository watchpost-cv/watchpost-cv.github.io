Convenient browser access

Watchpost provides memorable browser shortcuts for both the main server and the separately running Watchpost Agent. They avoid remembering port numbers or repeatedly typing localhost addresses by hand.

Watchpost

Use my.watchpost.cv to open the main Watchpost interface. On first use:

  1. Visit my.watchpost.cv?config.
  2. Keep localhost and port 7334 for a local instance, or enter a remote domain or IP address and port.
  3. Select Save, then Open.

Later visits to my.watchpost.cv forward directly to the saved address.

Watchpost Agent

The Agent has its own shortcut because its local management interface is a separate service:

  1. Visit agent.watchpost.cv?config.
  2. Keep localhost and port 7335, or configure the Agent's domain or IP address and port.
  3. Select Save, then Open.

Use agent.watchpost.cv for direct access afterwards.

Each shortcut is browser-local.

The two destinations are stored separately in the current browser profile. Configure them again on another browser, profile, or device, and return to the corresponding ?config URL when an address changes.

What the shortcuts do

These sites only navigate your browser to a configured address. They do not proxy either service, change network exposure, or replace secure remote deployment. See Agent architecture and Security model for the relevant boundaries.
