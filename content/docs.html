Watchpost design docs

Watchpost is in product definition. These documents describe the intended contracts and operating model so implementation can be judged against something firmer than a feature list.

Current status

No Watchpost runtime has been released. Commands and configuration shown as proposals are labelled accordingly and may change before the first usable build.
