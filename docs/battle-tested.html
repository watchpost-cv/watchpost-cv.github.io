Battle tested

A direct index of the tests, recovery drills and release checks behind Watchpost's current claims.

What is exercised

  • Normal and race-enabled Go suites for Watchpost and Watchpost Agent.
  • Authentication, durable sessions, audit atomicity, pairing and first-telemetry journeys.
  • Backup, restore, corruption recovery, bounded ingestion fuzzing and release smoke tests.
  • Transactional systemd lifecycle models plus native Linux service lifecycle CI.
  • Nift page builds, local-link checks, accessibility structure and responsive overflow checks.

Boundaries

This is retained engineering evidence, not a security certification or a production-readiness promise. Cross-compilation does not prove runtime support, a scripted journey is not a usability study, and a bounded fuzz run is not exhaustive.
