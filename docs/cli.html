Command-line administration

watchpost setup --email-file /run/secrets/admin-email --password-file /run/secrets/admin-password
watchpost config show --json
watchpost reset --auth --confirm "WATCHPOST AUTH"
watchpost reset --all --confirm "WATCHPOST ALL"

sudo watchpost-agent reset --auth --confirm "WATCHPOST-AGENT AUTH"
sudo watchpost-agent reset --all --confirm "WATCHPOST-AGENT ALL"

The agent additionally supports setup, configure, pair, rotate, unpair and JSON status commands. Stop services before resets. Agent authentication reset can discard incompatible authentication data; full reset can recover a damaged state file. Both retain backups and preserve service ownership. Update the installed executable before using commands from newer source. Full agent reset does not centrally revoke a lost machine.
