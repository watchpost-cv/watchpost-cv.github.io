Current limitations

WP01R–WP18R establish a locally proven Linux development candidate. They do not authorize a public production-readiness claim.

  • The remote host collector supports Linux; macOS and Windows artifacts are cross-built but lack equivalent real-runner collector smokes.
  • Endpoint checks and SNMP polling are immediate rather than durably scheduled.
  • SNMP is read-only. Cameras, arbitrary consumer IoT, PLC writes, and building-control commands remain future research.
  • The built-in investigation provider does not infer causality; production model-provider configuration and evaluation remain unfinished.
  • Several rules, notifications, incidents, actions, and fleet workflows still need richer management UI.
  • Fleet federation lacks sustained two-node partition and reconciliation evidence.
  • Backups require a cleanly stopped node; online encrypted scheduled backup is not implemented.
  • The local soak is bounded, not a multi-day or large-fleet capacity result, and no external security assessment has been completed.
Authority boundary

Watchpost is not a safety system, SCADA/HMI, or autonomous remediation engine. Missing evidence is never healthy evidence, and model output is never authorization.
